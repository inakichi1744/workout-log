# WORKOUT LOG 🏋️

ジムでのトレーニングをスマホでサッと記録できる筋トレ記録アプリです。

**▶ アプリを開く: https://inakichi1744.github.io/workout-log/**

iPhoneのSafariで開き、共有メニューから「ホーム画面に追加」すると、アプリのように全画面で使えます。

## 主な機能

- **ワークアウト記録** — 種目・重量・回数をプルダウンで選ぶだけ。前回の重量・回数をワンタップでコピー
- **カレンダー** — トレーニングした日に印がつき、日付タップで過去の記録を表示
- **部位別の履歴** — 胸・背中・肩・腕・脚・体幹ごとに記録を振り返り
- **休憩タイマー** — 30秒〜3分のプリセット。終了時は熱いメッセージが全画面に表示
- **データバックアップ** — 記録をJSONファイルとして書き出し・読み込み（機種変更対策）
- **ログコピー** — 記録をテキスト化してコピーし、AIに相談できる

## データについて

記録はすべて端末のブラウザ内（localStorage）に保存されます。サーバーには一切送信されないため、トレーニングデータが外部に公開されることはありません。

## 技術構成

- HTML / CSS / JavaScript の1ファイル構成（`index.html`）
- フレームワーク・ビルド不要、GitHub Pagesでホスティング
